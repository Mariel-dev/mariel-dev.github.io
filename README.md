# Portfolio — Trésor Mariel ALLOGNON

## Structure du dossier

```
portfolio/
├── index.html          ← Le site complet (ne pas renommer)
├── photo.jpg           ← TA PHOTO (remplace ce fichier)
├── visuals/
│   ├── project1.jpg    ← Visuel Projet 1 (implants intraoculaires)
│   ├── project2.jpg    ← Visuel Projet 2 (non-observance thérapeutique)
│   └── project4.jpg    ← Visuel Projet 4 (PIB Bénin)
└── README.md           ← Ce fichier
```

## Comment ajouter ta photo

1. Prends ta photo professionnelle
2. Renomme-la exactement : **photo.jpg**
3. Place-la dans le dossier `portfolio/` (à côté de index.html)
4. Ouvre index.html dans ton navigateur pour vérifier

## Comment ajouter les visuels de projets

1. Génère les 3 images avec ChatGPT/DALL·E (prompts fournis séparément)
2. Renomme-les exactement : project1.jpg, project2.jpg, project4.jpg
3. Place-les dans le dossier `portfolio/visuals/`

## Comment voir le site en local

Double-clique sur **index.html** → il s'ouvre dans ton navigateur
Aucun serveur, aucune installation requise.
